📈 Statistik-Kanäle

Erstelle Sprachkanäle, die automatisch Server-Statistiken anzeigen (z. B. Mitgliederzahl, Bots, Rollen, Boosts). Die Kanäle werden in einer Kategorie erstellt und sind für Mitglieder nicht betretbar.

⭐ Level-System

Mitglieder bekommen für jede Nachricht (und optional für Zeit im Voice-Chat) XP. Ist genug XP gesammelt, steigt das Level und eine Nachricht wird in einem Kanal deiner Wahl gesendet. Jedes weitere Level braucht mehr XP als das davor.

💬 XP pro Nachricht
Pro Nachricht wird eine zufällige XP-Zahl zwischen Min. und Max. vergeben. Der Cooldown verhindert, dass Mitglieder durch Spam-Nachrichten schneller leveln.
📊 XP-Anforderung pro Level
Jedes Level benötigt mehr XP als das vorherige: benötigte XP = Basis-XP + (aktuelles Level × Steigerung).
🎉 Level-Up Nachricht
Platzhalter: {user}, {level}
Wird nur vergeben, solange ein Mitglied nicht stummgeschaltet/taub ist und sich nicht im AFK-Kanal befindet.

Lade Rollen...

🎁 Level-Rollen

Schichtarten

Lege verschiedene Schichtarten an (z. B. Polizei, Feuerwehr, Rettungsdienst) und wähle pro Schichtart, welche Rolle(n) sie starten dürfen. 📤 Abmelde-System

Teammitglieder können sich über einen Button im gewählten Kanal abmelden (Zeitraum + Grund per Formular) und bekommen dabei automatisch eine "Abgemeldet"-Rolle. Jede Ab- und Anmeldung wird zusätzlich als Übersicht in einem Log-Kanal gepostet.

Hier wird die Nachricht mit den 2 Buttons "Abmeldung erstellen" und "Anmelden" gepostet.
Hier sieht das Team, wer sich von wann bis wann und aus welchem Grund abgemeldet hat.
Wird automatisch vergeben, sobald jemand eine Abmeldung erstellt, und wieder entfernt, sobald er sich anmeldet.

📝 Bewerbungen

Erstelle beliebig viele Bewerbungen (z.B. Team-Bewerbung, Moderator-Bewerbung). Für jede Bewerbung wird eine Nachricht mit einem "Bewerben"-Button in einem Kanal deiner Wahl gepostet. Klickt jemand darauf, läuft die Bewerbung komplett über Direktnachrichten (DMs) mit dem Bot ab – die Fragen werden dort nacheinander gestellt. Die fertige Bewerbung wird anschließend in einen Kanal deiner Wahl gepostet, wobei optional eine Rolle gepingt wird.

🎤 Voice Support

Richte einen Support-Warteraum ein. Wenn ein Nutzer den Kanal betritt, wird eine Benachrichtigung mit „Support übernehmen“- und „Supportfall beenden“-Buttons gesendet. Das Embed kann individuell angepasst werden.

Wenn ein Nutzer diesen Kanal betritt, wird eine Support-Anfrage gestartet.
Der Bot joint automatisch in den Warteraum-Kanal und spielt die hochgeladene Audiodatei ab, sobald ein Mitglied beitritt. Danach verlässt der Bot den Kanal wieder.
Erlaubt sind gängige Audioformate (MP3, WAV, OGG), max. 4MB.
Hier werden die Support-Anfragen mit Buttons gepostet.
Wähle eine Rolle, die bei neuen Support-Anfragen gepingt wird.
