# Frontend

Geplante Aufteilung der Weboberfläche:

- `css/`: Stylesheets für Startseite und Dashboard
- `js/`: Browser-JavaScript
- `seiten/`: HTML-Seiten, sobald Routing und Hosting darauf angepasst sind

Die bestehenden Dateien bleiben zunächst an ihren bisherigen Pfaden, damit lokale Express-Auslieferung und Vercel-Routing nicht versehentlich brechen.
