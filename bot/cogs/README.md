# Discord-Cogs

Ziel: einzelne Erweiterungen für Moderation, Tickets, Community, Musik und Verwaltung.

Jedes Cog soll eigene Events/Befehle enthalten und über einen zentralen Einstiegspunkt geladen werden. Bestehende Funktionen werden erst hierher verschoben, wenn ihre Abhängigkeiten geprüft und Tests ergänzt wurden.
